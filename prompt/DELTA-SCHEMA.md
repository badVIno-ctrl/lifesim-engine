# DELTA-SCHEMA (v13.1)

Один блок в конце ответа: `<delta>{ … }</delta>`. Валидный JSON, без комментариев, без текста после.
Все поля необязательны, кроме `time`. Лишние ключи игнорируются.
Все `step` — шаги по лестнице, не абсолютные значения. За один ход движок пропускает не больше одной ступени;
большее он сам обрежет и сообщит фактом.

## Ключи

| ключ | форма | зачем |
|---|---|---|
| `time` | `{ "minutes": 25 }` или `{ "days": 1 }` | **обязательно.** Сколько занял ход |
| `channel` | `"звук"` \| `"тело"` \| `"запах"` \| `"вкус"` \| `"зрение"` | ведущий канал сцены |
| `scene` | `{ "location": "…", "posture": "…", "light": "…", "participants": ["…"] }` | где и в каком положении |
| `stress` | `{ "segments": 2, "reason": "…" }` | ±3 сегмента за ход, 5 сегментов = ступень |
| `fatigue` / `hunger` / `thirst` | `{ "step": 1 }` | шаг по лестнице тела |
| `health` | `{ "step": 1, "cause": "…" }` | ухудшение или восстановление; `cause` обязателен при ухудшении |
| `wounds` | `[{ "zone": "левая кисть", "step": 1, "cause": "…" }]` | новая рана или её заживление |
| `bleed` | `{ "step": 1, "cause": "…" }` | кровотечение |
| `money` | `{ "delta": -12, "reason": "ночлег" }` | если денег не хватит, списание отклоняется целиком |
| `inventory` | `{ "add": [{ "name":"…", "qty":1, "wear":"цело" }], "remove": [{ "name":"…", "qty":1 }], "wear": [{ "name":"…", "step":1 }] }` | имущество; списать можно только то, что есть |
| `npc` | `[{ "name":"…", "attitudeStep":1, "reason":"…", "promise":"…", "promiseKept":"…" }]` | сдвиг отношения только с `reason` |
| `skills` | `[{ "name":"…", "step":1, "justification":"…" }]` | рост требует `justification`: три применения в риске + разбор провала |
| `milestone` | `{ "granted": true, "criterion": "project" }` | критерий только из: `project`, `fear`, `price` |
| `revelation` | `{ "criterion": "near_death", "what": "…" }` | перелом. Критерий: `model_broken`, `near_death`, `own_failure_analyzed`. Не чаще раза в 10 ходов |
| `effects` | `{ "add": [{ "name":"…", "expiresInTurns": 3 }], "remove": ["…"] }` | временные состояния |
| `trace` | `"след, оставленный в мире"` | что заметят другие |
| `hooks` | `{ "add": [{ "text":"…", "window": 5 }], "resolve": ["…"], "sleep": ["…"] }` | крючки; лимит 7 |
| `consequences` | `{ "add": [{ "what":"…", "cause":"…", "window": 3 }], "fire": ["…"] }` | отсроченные последствия; лимит 5 |
| `fronts` | `[{ "name":"…", "progressStep": 1, "advanceConditionMet": true, "justification":"…" }]` | без подтверждённого условия и обоснования — отклонение |
| `obligations` | `{ "add": [{ "what":"…", "amount": 40, "dueDay": 6 }], "settle": ["…"] }` | сроки; из них движок делает календарное давление |
| `unknowns` | `{ "add": ["…?"], "resolve": ["…"] }` | реестр неустановленного |
| `goals` | `{ "add": ["…"], "done": ["…"] }` | цели персонажа |
| `precedent` | `"как мир решил спорный случай"` | запомнить трактовку на будущее |
| `terminal` | `{ "kind": "death", "cause": "…" }` | только при уже установленной смертельной причине в состоянии |
| `note` | `"одна строка в журнал"` | пометка в ledger |

## Минимальная дельта

```json
{ "time": { "minutes": 10 }, "channel": "звук" }
```

## Типичная дельта

```json
{
  "time": { "minutes": 45 },
  "channel": "запах",
  "scene": { "location": "задний двор мастерской", "posture": "на корточках", "light": "сумерки", "participants": ["Кольб"] },
  "money": { "delta": -6, "reason": "задаток за металл" },
  "fatigue": { "step": 1 },
  "stress": { "segments": 2, "reason": "Кольб запомнил лицо" },
  "npc": [{ "name": "Кольб", "attitudeStep": -1, "reason": "вы отказались назвать заказчика" }],
  "unknowns": { "add": ["чей знак выбит на ящике с металлом"] },
  "hooks": { "add": [{ "text": "Кольб пришлёт человека за долей", "window": 4 }] },
  "note": "задаток отдан, имя заказчика не названо"
}
```

## Если эндпоинт требует JSON по схеме

Верни объект `{ "prose": "текст сцены", "delta": { … те же ключи … } }` без тегов `<delta>`.
