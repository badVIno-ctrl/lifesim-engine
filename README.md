# Симулятор мира · v13.1 (PWA)

Текстовый симулятор жизни одного человека. Модель пишет прозу, числа считает движок.
Играется в браузере на ПК и на телефоне, ставится как приложение, работает без сервера и без аккаунтов.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 — игра работает. Ключ модели вводится внутри, в «Настройках».
Без ключа приложение тоже запускается и само ведёт на экран настроек.

Никаких docker, миграций, `.env`, отдельной сборки клиента и сервера, глобальных утилит.
`npm run dev` поднимает и клиент, и LLM-прокси — прокси живёт middleware'ом внутри Vite (`server/vite-plugin-llm-proxy.ts`).

### Продакшн

```bash
npm start
```

Сборка + запуск одной командой (Hono раздаёт `dist/` и тот же прокси) — http://localhost:4173.
Порт меняется переменной `PORT`, но это необязательно.

### Остальные команды

| Команда | Что делает |
| --- | --- |
| `npm test` | 124 тест ядра, контура хода, хранилища, паков, схемы и промптов |
| `npm run typecheck` | строгая проверка типов |
| `npm run build` | только сборка в `dist/` |

## Установка как приложения

- **Android / Chrome:** меню → «Установить приложение».
- **iOS / Safari:** Поделиться → «На экран «LДомой»».
- **ПК / Chrome, Edge:** значок установки в адресной строке.

Service worker собирается только для продакшн-сборки (`npm start`), чтобы не мешать разработке.
Оффлайн открывается оболочка, читаются сохранённые партии и панель состояния; новый ход требует сети.

## Где что лежит

```
src/          ядро — изоморфное, без fs/path/process
  engine.ts     единственная точка изменения состояния (applyDelta, calendarPressure, audit)
  session.ts    контур хода: сборка контекста, локальные команды, ретрай, откат
  storage/      адаптер хранилища: indexeddb (браузер), fs (CLI/тесты), memory
  ui/           React-оболочка: экраны и компоненты, без игровой логики
server/       тонкий прокси к LLM и больше ничего
prompt/       CORE.md и DELTA-SCHEMA.md уходят в модель; INIT.md — только для инициации
packs/        сеттинги — обычные JSON той же формы, что state.example.json
test/         регрессия ядра и новой логики
```

## Как добавить свой сеттинг

Скопируйте `packs/grauberg.json`, правьте содержимое, положите рядом под своим именем.
Пак появится на экране выбора сам: имя файла — это id пака, код не трогается.
Негодный файл не роняет приложение — показывается список причин.

Обязательное в паке: `meta` (персонаж, сеттинг, валюта, жёсткость), `economy.anchors`,
хотя бы один фронт с `advanceCondition`, хотя бы один NPC и хотя бы один пункт `unknowns`.

## Как устроен ход

1. Игрок пишет действие (или жмёт кнопку команды).
2. Локальные команды (снапшот, аудит, лог, цены, откат, экспорт) выполняются кодом и в модель не уходят.
3. Иначе собирается контекст: CORE + DELTA-SCHEMA → снапшот → рендер состояния → блок движка (факты и сроки) → последние 8 сообщений → реплика игрока.
4. Модель возвращает прозу и дельту (JSON-схемой или блоком `<delta>`).
5. `applyDelta` — единственное место, где меняются числа. Отклонённое становится фактом мира и уходит в следующий ход.
6. Состояние сохраняется в IndexedDB, предыдущее — в стек отката (20 шагов).

## Приватность

Ключ хранится только в `localStorage` браузера и уходит ровно в тот эндпоинт, который вы указали.
Прокси не логирует ни ключ, ни тела запросов и ничего не хранит. Сохранённые партии не покидают устройство.

## Голосовой ввод

Кнопка 🎤 рядом с полем ввода. Два режима, выбираются в Настройках (по умолчанию — авто):

1. **Браузером** (Web Speech API) — бесплатно, без токенов, с черновиком по ходу речи. Chrome и Safari.
2. **На эндпоинте** (`POST /audio/transcriptions`, модель `whisper-1` по умолчанию) — запись через `MediaRecorder`,
   уходит через тот же локальный прокси `/api/llm`, тратит квоту. Фолбэк для Firefox.

Правило: **голос никогда не отправляет ход сам** — только наполняет поле ввода. Ход необратим и стоит токенов,
поэтому решение «отправить» остаётся за игроком. Исключение одно: если поле пусто и сказана локальная команда
(«снапшот», «аудит», «команда откат») — она выполняется сразу: модель не задета, состояние не портится.
Синонимы типа «назад» или «сохрани» требуют явного слова «команда» — иначе «иду назад к гавани» съело бы ход откатом.

Диктуемая пунктуация работает только в конце фразы («иду к гавани точка» → «иду к гавани.»), чтобы не сломать
«точка сборки у маяка». Отдельно есть тумблер «читать прозу вслух» (`speechSynthesis`, тоже бесплатно).

Границы, о которых надо знать: микрофон требует https или localhost; в Safari/iOS речь уходит на серверы Apple,
в Chrome — Google; Web Speech обрывается на длинных паузах — нажмите микрофон снова.
